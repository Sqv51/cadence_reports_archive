## Notes

1. **Unconstrained Design:** The synthesis shows infinite slack because the design lacks proper clock constraints in the input RTL. This means timing is not validated - the 4 GHz target is aspirational.

2. **Partial RTL:** D-cache core modules were excluded due to signal declaration order issues. The synthesis includes:
   - ✅ Core pipeline (fetch, decode, issue, execute)
   - ✅ I-cache
   - ✅ D-cache wrappers (not core)
   - ✅ Custom multiplier extensions

3. **Next Steps:**
   - Fix D-cache core RTL declaration issues
   - Re-run with complete RTL
   - Add proper clock constraints for timing closure
   - Run Place & Route (Innovus) for accurate power/area
