KEY INSIGHTS
────────────────────────────────────────────────────────────────────────────────

1. LATENCY² DOMINATES EDP
   - Reducing latency 16.5× (33→2) gives 272× EDP improvement
   - Even with same power, faster execution = much better energy efficiency

2. WHY MUL WINS
   ✓ Parallel combinational logic completes in 2 cycles
   ✓ Fits perfectly in dual-issue pipeline (no stalls)
   ✓ At 7nm, logic is cheap; registers dominate power (53-80%)
   ✓ Higher gate count amortized over 16.5× fewer cycles

3. WHY MULE/CBM LOSE
   ✗ Sequential iterative processing takes 9-33 cycles
   ✗ State machine overhead adds complexity
   ✗ Pipeline bubbles from multi-cycle latency
   ✗ Register power doesn't scale as well at 7nm
